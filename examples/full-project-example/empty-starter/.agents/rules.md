# Crustini Starter Rules

- Write beginner-facing examples in `.flour`.
- Keep the first screen useful: state, update, draw, input, and visible output.
- Use `number`, `bool`, `text`, `Color`, and `Button` as user-facing types/names.
- Keep mutation in `update()` when `update()` exists.
- `draw()` should render from state.
- Use `rx proof`, `rx emit`, and `rx bake` before calling the starter ready.
