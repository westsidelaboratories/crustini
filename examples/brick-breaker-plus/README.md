# Brick Breaker Plus

This is a larger runnable Crustini example for the current compiler.

The active language direction is [`../../new-spec.md`](../../new-spec.md). This example may still use compatibility syntax until the compiler catches up.

It uses a `320x240` playfield, bricks, lives, win/loss state, mouse control, and keyboard control.

## Authored Files

```txt
examples/brick-breaker-plus/
  app.flour
  README.md
```

Everything under `.bakery/` is generated by `rx`. Do not edit it as source.

## Run It

From the repo root:

```bash
cargo run --bin rx -- examples/brick-breaker-plus/app.flour
```

Once `rx` is installed:

```bash
rx examples/brick-breaker-plus/app.flour
```

Controls:

- Left/right arrows move the paddle.
- Mouse click also starts the game and moves the paddle.
- `A` or `Start` starts the game.
- `Esc` quits the native preview window.

## Compile Path

Emit generated Rust:

```bash
cargo run --bin rx -- emit examples/brick-breaker-plus/app.flour
```

Bake the generated app crate:

```bash
cargo run --bin rx -- bake examples/brick-breaker-plus/app.flour
```

Run preview:

```bash
cargo run --bin rx -- examples/brick-breaker-plus/app.flour
```

Generated by `rx`:

```txt
examples/brick-breaker-plus/.bakery/
  Cargo.toml
  src/lib.rs
  preview/
  target/
```

The generated Rust app crate implements `crustini_core::CrustiniApp`. The native preview shell stays outside the language compiler.
